# Приложение родственного древа
Создание своего древа семьи с визуальным отображением каждого из члена рода. Каждый родственник имеет биографию, фото, данные о жизни человека, месте жительства, документы связанные с личностью человека.
 
### Запуск приложения:
$env:HTTP_ADDR=":8080"; $env:LOGGER_LEVEL="DEBUG"; $env:LOGGER_FOLDER=".\logs"; go run .\cmd\family_tree_app
